# AEL Products

This directory contains brand system documentation for individual AEL products and projects.

## Structure

Each product has its own subdirectory with:
- `README.md` — Product overview, status, brand notes
- `design.md` — Product-specific design guidelines (if applicable)
- `tokens.json` — Product-specific design tokens (if applicable)
- `components.md` — Product-specific component variations (if applicable)
