# 05 — AEL Content Guidelines

## Tone of Voice

AEL's voice is **confident, precise, and visionary** — never hype-driven or inflated.

| Quality | Description | Applies To |
|---------|-------------|------------|
| Confident | Speaks with authority, not arrogance | All copy |
| Precise | Every word earns its place | Headlines, taglines |
| Visionary | Big-picture framing | Philosophy, bio |
| Direct | Clear, no filler | Buttons, labels |
| Warm | Professional but human | Contact, about |

### Voice Characteristics

- **No buzzwords**: Avoid "revolutionary," "disruptive," "game-changing"
- **No superlatives**: Unless demonstrably true (certifications, metrics)
- **Own the craft**: Use "I build," "I design," "I architect" — not "we"
- **Dual language**: Arabic and English side by side in philosophy/brand content

## Writing Standards

### Capitalization

| Rule | Example |
|------|---------|
| **Sentence case** for headings | "I build systems that generate outcomes" |
| **Title case** for proper names | "AEL Digital Studio" |
| **Lowercase** for tag labels | "visionary architect" (in tag component) |
| **UPPERCASE** for badges | "NEW", "BETA", "HOT" |
| **Sentence case** for buttons | "Explore my work" (not "Explore My Work") |
| **Title case** for section names | "The Three Pillars" |

### Numbers

- Use numerals (0–9)
- Large numbers: 1,000+ (comma separator)
- Percentages: 100% (not "one hundred percent")
- Years: 2026 (not '26)
- Phone: +20 111 330 0073

### Dates

- Format: "2026" (year only on portfolio)
- Certifications: "2024", "2025", etc.
- Copyright: "© 2026 Ayman Elmasry — AEL Digital Studio"

### Typographic Conventions

- **Emphasis**: Use `*italic*` for quotes, `**bold**` for key terms
- **Code**: Use `` `backticks` `` for commands, file names, code
- **Quotes**: English quote on first line, Arabic quote below
- **Attribution**: `— Ayman Elmasry` on a new line, right-aligned for Arabic
- **Lists**: Use `-` for unordered, `1.` for ordered
- **Section dividers**: `---` horizontal rule

## Content Patterns

### Bio Formats

**Short (social/hero)**
```
Visionary Architect · AI Orchestrator · Brand Designer
```

**Medium (GitHub profile)**
```
Ayman Elmasry — Visionary Architect, AI Orchestrator, and Brand Designer at AEL Digital Studio.
Design drives the vision, AI powers the build.
```

**Full (about section)**
```
Define the vision — orchestrate AI to build it. Design drives the vision, AI powers the build.
```

### Tagline Variations
- "Define the vision — orchestrate AI to build it."
- "Design drives the vision, AI powers the build."
- "I build systems that generate outcomes."
- "Artist Over Tool · Substance Over Noise · Engine Over Output"


## Bilingual Content

### When to Use Arabic
- Quote repetitions (English then Arabic)
- Main title translation
- Social bio (Arabic version)

### When to Use English Only
- Technical documentation
- UI labels
- SEO metadata
- GitHub content

### Dual-language Pattern
```markdown
**Title (EN)** | Visionary Architect · AI Orchestrator · Brand Designer
**Title (AR)** | مهندس رؤية · مخرج ذكاء اصطناعي · مصمم هويات
```

## Prohibited Content

- **No superlative claims** without evidence
- **No competitor references** (avoid naming other designers/studios)
- **No client names** without explicit permission
- **No stock phrases** — every piece of copy should be original
- **No emoji in formal content** (brand docs, UI labels)
- **No ALL CAPS** except badges and acronyms
- **No underlines** except links (and use `text-decoration: none` on those)
- **No vague claims** like "best in class" or "leading"
